# Бесплатный хостинг 24/7 (GitHub Actions)

Репозиторий уже готов к деплою: воркфлоу `.github/workflows/bot.yml` стартует
бота каждые 30 минут, каждый новый запуск отменяет предыдущий — получается
непрерывная работа. Сигналы бот сам коммитит в `signals.log` (их видно в
репозитории и они доступны для `review.py`).

Важно: репозиторий должен быть **публичным** — на публичных репо Actions
бесплатны без лимитов; приватному не хватит 2000 минут/мес для 24/7.

## Шаги (один раз, ~3 минуты)

1. Зайди на github.com → New repository → имя `polysign`, Public,
   без README (галочки не ставить) → Create.
2. В этой папке (polysign):

   ```
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/polysign.git
   git push -u origin main
   ```

3. Готово. Расписание `*/30 * * * *` подхватится само (первый запуск — в
   течение получаса). Чтобы стартануть сразу: вкладка Actions → polysign-bot →
   Run workflow.

## Как проверять

- Сигналы: файл `signals.log` в репозитории (обновляется сам после каждого
  сигнала; подтяни локально `git pull`) либо Actions → последний запуск → лог.
- Статистика зашедшего: `git pull && python review.py`.
- Если в логе раннера `live=0, финалов=0` при идущих матчах — ESPN заблокировал
  IP раннера. Бот ходит на `site.web.api.espn.com` именно поэтому; детали —
  README, раздел «Подводные камни внешних API».
- Остановка на сервере: Actions → polysign-bot → кнопка Disable workflow.

## Важно про push из локальной копии

Серверный бот сам коммитит `signals.log`, поэтому перед своим push всегда
делай `git pull --rebase --autostash` и **не коммить локальный signals.log**
(локальный бот с 2026-08-16 пишет в `signals.local.log`, он в .gitignore).
Если пуш отклоняют повторно — проверь, что не застрял rebase:
`git rebase --abort`, затем `git pull --rebase` заново.

## Telegram (настоятельно рекомендую до пуша)

На сервере консоль никто не смотрит — сигналы должны приходить в телегу:

1. @BotFather → /newbot → получишь токен.
2. Напиши своему боту любое сообщение, затем узнай chat_id через
   @userinfobot (или `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).
3. В `config.json` впиши:

   `"telegram": {"token": "123:ABC...", "chat_id": "123456789"}`

4. Сделай коммит и запушь вместе с конфигом (токен бота — не секрет уровня
   кошелька, но если не хочешь его в публичном репо — вынеси в переменную
   и добавь как Secret в воркфлоу).

## Локальный фоновый режим (уже настроен на этой машине)

- Бот запущен скрытым процессом + ярлык в автозагрузке (Startup) — стартует
  сам при входе в Windows. Повторный запуск не создаст дубль (лок на порту).
- Лог: `bot_run.log`, сигналы: `signals.log`.
- Остановить: `taskkill /IM python3.13.exe /F` (или убить процесс с портом 47891).
- Убрать автозапуск: удалить файл
  `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\polysign.lnk`
